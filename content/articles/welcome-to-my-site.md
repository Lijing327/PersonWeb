# 欢迎来到我的个人网站

你好，我是溪午听风。这个站点是我的**工作名片 + 写作园地**：一边展示正在做的产品和项目，一边记录技术实践与少量生活笔记。

## 你可以在这里找到什么

### Work（工作面）

- **案例 / 项目**：做过的产品和工程实践
- **产品 / 工具**：可试用、可了解的能力与 Demo
- **文章**：部署、前端、AI 应用等可检索的长文
- **关于**：我是谁、擅长什么、如何联系

### Life（生活面）

如果从首页进入「生活」世界，会看到更轻松的日常与随笔，和 Work 的专业语气刻意分开。

## 技术栈（简要）

- 前端：Nuxt 3 + Vue 3 + TypeScript
- 内容：Markdown / YAML（Git 作为文章正文来源）
- 后端：.NET 8 WebAPI（业务与运营数据）
- 部署：静态前端 + API 分离

站点本身也是我的实验场：模块化后台、主题系统、AI 助手入口，都会在这里迭代。

## 如何阅读

1. 想快速了解我 → 先看「关于」和首页项目
2. 想跟部署 / 前端实战 → 打开「文章」按分类筛选
3. 有合作或问题 → 用右下角助手或「联系合作」

感谢你的到访。若某篇文章写得太浅或过时，欢迎留言；我会优先把「能帮到人」的内容写扎实。
