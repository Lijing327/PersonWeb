# 01｜购买阿里云 ECS 后，我遇到的第一个坑：不知道怎么用服务器

## 问题场景

初次拿到云服务器，一脸懵：

- 登录不上去？
- 黑黑的命令行不会敲？
- 不知道怎么上传文件？
- 不知道在哪里放网站？

买服务器的按钮很好点，点完才发现：**没有人送你一份「如何第一次开机」说明书**。

## 核心概念

实际上，**云服务器就是一台「无界面」的 Linux 电脑**。

它没有鼠标桌面（默认），只有一行行终端。但核心逻辑和你的个人电脑一样：

1. **硬盘**：放系统、网站文件、日志  
2. **IP 地址**：它的门牌号，公网靠这个找到它  
3. **SSH**：远程登录通道（文字版「远程桌面」）  
4. **安全组**：云厂商的防火墙，端口没放行等于门没开  

## 第一次该做什么（最小路径）

1. 在控制台重置并保存 **root / 自定义用户密码**，或配置 SSH 公钥  
2. 安全组放行 **22**（SSH）、之后还会用到 **80/443**  
3. 本机安装终端工具（Windows 可用 PowerShell / Windows Terminal / FinalShell）  
4. 登录：

```bash
ssh root@你的公网IP
```

第一次会问是否信任指纹，输入 `yes`，再输入密码。

## 为什么会「不知道怎么用」

我们习惯了 Windows 图形界面。在 Linux 服务器上，常见操作都是命令：

| 你想做的事 | 命令方向 |
| --- | --- |
| 新建文件夹 | `mkdir` |
| 看有什么文件 | `ls` |
| 编辑配置 | `nano` / `vim` |
| 装软件 | `apt install` |

不会敲很正常。本系列不讲玄学原理，只讲**怎么做、怎么避坑**。
